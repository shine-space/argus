---
title: "Skill 与工具"
---

复用工作方法，并通过 HTTP 或 MCP 连接外部能力。

## Skill 的用途

Skill 保存可复用的方法、适用条件和输出要求。它可以配合知识、模型与执行环境处理任务。提供某个 Skill 的名称，并不代表其依赖资源已经就绪。

## HTTP 和 MCP 工具

HTTP 工具描述请求与结果；MCP 工具通过已配置的服务发现能力。凭证由平台连接管理，调用仍需通过资源和当前业务权限检查。

## 安装和版本

按授权目录选用或安装 Skill。更新时检查依赖和对现有任务的影响。客户自己的内容与平台预置私有资源分别确定导出范围。

## 使用反馈

用户纠正可以形成改进候选。是否修改规则、采用新版本及如何验证，需经过明确的评估与发布过程。一次点赞或确认不能直接等同于准确率提升。

接口参考包含[HTTP/MCP 工具](/api/#group-tools)。Skill 管理的可用接口和导出能力以交付版本提供的开发包为准。
