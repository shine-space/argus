使前端、API、应用配置和后端镜像保持可管理的兼容关系。

## 接口与产品版本

Core API 使用 `/api/v1`，部分既有接口使用其他明确路径。路径中的 v1 不是软件产品版本号。安装版本、开通模块与发布配置共同决定接口可用范围。

## 前端与后端

记录前端开发包适配的后端版本和接口合同。升级前检查必填字段、枚举、对象权限、事件、文件和错误语义，不仅检查 URL 是否仍存在。

## 应用与资源版本

应用采用更新时保留明确资源版本，历史任务按原记录回查。新的输入输出合同需要调用方适配，不能把旧任务改投给另一个执行器。

## 数据结构变化

业务记录出现结构不兼容时，执行显式迁移。保留原数据和来源，不通过前端忽略错误或强制覆盖实现升级。

## 开发包和文档

本网站提供接口参考和集成方法；具体交付版本的兼容清单由运行包与开发包共同提供。下载的 OpenAPI 可以用于类型生成与请求校验，但不能授予接口访问权限。
