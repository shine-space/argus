title: "列出应用部署修订"
---

`POST /api/v1/applications/deployments/revisions/list`

请求发送到客户自己的本地部署实例，功能与权限以安装版本为准。

## 接口用途

List immutable deployment revisions

## 认证与权限

请求携带 `Authorization: Bearer <access_token>`。服务端检查当前身份、目标工作区及对应对象权限；接口可调用不意味着可以访问所有数据。

## 请求参数

请求类型：`application/json`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `workspace_id` | `string` | 是 | 目标工作区。仍需当前用户具有访问权限。；最短：`1`；最长：`100` |
| `deployment_id` | `string` | 是 | 最短：`1`；最长：`48` |
| `before_revision` | `integer (int64)` | 否 | 最小：`0` |
| `limit` | `integer` | 否 | 本次读取数量，范围见字段约束。；最小：`1`；最大：`100` |

该请求结构不接受未声明字段。

## 请求示例

下面是结构示例。尖括号内容必须替换为真实授权资源及满足字段约束的值；示例不会连接你的平台。

```json
{
  "workspace_id": "<workspace_id>",
  "deployment_id": "<按字段约束替换>"
}
```

```bash
curl --request POST "$BASE_URL/api/v1/applications/deployments/revisions/list" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  --data @request.json
```

## 返回结果

成功响应类型：`application/json`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `status` | `boolean` | 是 | 允许值：`[true]` |
| `code` | `string` | 否 | 按当前业务对象与接口合同提供。 |
| `message` | `string` | 是 | 按当前业务对象与接口合同提供。 |
| `data` | `ApplicationDeploymentRevisionList` | 否 | 按当前业务对象与接口合同提供。 |

### data 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | `array<ApplicationDeploymentRevision>` | 是 | 按当前业务对象与接口合同提供。 |
| `next_before_revision` | `integer (int64)` | 是 | 按当前业务对象与接口合同提供。 |
