title: "开发者概览"
---

通过稳定接口扩展本地部署的平台，不依赖后端源码。

## 开发边界

平台提供商业软件运行服务、受授权接口和按约定交付的前端开发包。业务界面可以在交付范围内修改；平台内核、执行引擎和服务端领域规则通过接口使用。

## 两种扩展方式

- 独立业务前端：使用客户平台地址、认证流程、公开接口和配套 SDK 构建页面。
- 业务系统集成：由客户或实施团队维护独立业务服务，通过批准的 HTTP/MCP 工具与平台协作。

平台内受控工作台包另有宿主和包版本要求。当前不能把任意远程 JavaScript 上传并当作平台内插件运行。

## 建议的接入顺序

先完成身份、工作区和当前应用上下文读取，再实现一次任务提交和原任务查询。随后接入文件、流式显示、业务记录及必要的写入。

每一步都覆盖无权限、版本变化、请求超时和重复操作。专业业务状态由相应领域服务返回，前端不自行将模型文字转换为已审批或已完成。

## 获取接口合同

从[接口目录](/api/)查看请求、参数和结果；也可下载[OpenAPI 合同](/openapi.json)。接口中出现的相对路径均属于客户自己的部署实例。文档站不提供可直接执行业务的公共 API。
