---
title: "Agent 与数字员工"
---

配置数字员工的职责、知识、数据和工具，让它在授权范围内工作。

## 定义工作职责

说明员工负责的任务、输入与输出、何时需要追问以及哪些步骤交给人办理。岗位名称应对应可以复核的业务结果。

## 连接能力

为 Agent 选择需要的模型、知识、数据、Workflow 和工具。按任务授予必要资源范围；不在提示词里放置账号、密码或永久密钥。

## 测试与发布

准备正常、缺失信息、无权访问和工具失败等样例。检查员工能否给出有依据的结果、明确人工边界并保留运行记录，然后按应用发布流程使用。

## 管理持续运行

跟踪实际任务状态、工具回执和结果。暂停或撤回访问后，新请求应遵循当前状态；在途任务如何处理需遵守该版本及业务合同。

通过[Agent 接口](/api/#group-agents)可管理授权资源；业务前端优先从应用运行入口调用，以保持应用上下文。
