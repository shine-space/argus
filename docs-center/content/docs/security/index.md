---
title: "安全与权限"
---

让前端、数字员工和外部系统遵循同一授权边界。

## 身份与角色

每位使用者使用可追溯身份。企业角色、团队或项目参与、应用授权和具体资源权限共同决定访问范围。不要让全部用户共用管理员账号或永久管理员令牌。

## 服务端授权

前端控制可见性和操作体验，后端逐次判断真实权限。对象 ID、版本引用、共享链接或工具名称都不能代替授权。企业管理员的配置权限与读取敏感业务内容的权限应按实际策略分别配置。

## 连接与凭证

业务系统和模型连接使用各自授权范围。凭证由约定的平台或企业密钥设施保管，不放进前端构建变量、提示词、下载的 Skill 或浏览器日志。

## 文件和衍生结果

原文件、摘录、摘要、报表及消息推送都需要合适的接收范围。转岗、离职、项目结束或临时授权到期后，验证后续检索、运行、下载与分发是否停止。

## 业务操作

区分查询、草稿、提交、审批和正式生效。关键操作由领域服务和当前权限判断，人工确认必须针对具体对象与版本。

## 运行记录

保留定位问题所需的任务、对象与错误标识，按企业策略控制访问和保留时间。日志不记录密钥、完整敏感提示词或不必要的业务原文。
