了解朝夕智能平台，使用本地部署的软件，并通过接口扩展企业应用。

## 选择运行方式

当前提供[商业授权的本地部署版](/deployment-model/)。企业在自己的环境中管理数据与应用；后端以镜像交付，前端开发包和可修改范围按授权清单提供。[了解部署方式](/deployment/)。

云端服务即将上线。当前文档中的接口请求均指向企业自己的部署实例。

## 文档与软件版本

接口参考依据 Core API v1 合同编制，并补充现有登录及应用模块接口。具体可用功能以安装版本、开通模块和当前用户权限为准。更新软件前，请先查看[版本兼容](/compatibility/)。
