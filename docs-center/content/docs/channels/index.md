---
title: "渠道与结果分发"
---

将应用连接到获授权渠道，区分发送回执和业务办理结果。

## 选择渠道

根据安装版本和项目范围配置飞书、企业微信等可用渠道。企业应用安装、成员范围、连接授权和消息能力需要分别完成配置。

## 绑定应用

渠道调用继续使用同一应用和数字员工。渠道身份、会话、当前绑定和资源权限共同确定可执行范围，不通过创建另一个员工绕过原业务规则。

## 发送与回执

对外消息、文件或业务动作应有明确发送对象、内容和授权。平台返回的发送状态以渠道实际回执为准；超时或未知结果需要先查询原记录，不能盲目重复发送。

## 权限变化

员工离职、渠道撤权或应用停用后，应按当前权限停止后续使用。旧消息中的链接与历史绑定不能恢复已撤销的权限。

API 见[应用渠道与身份](/api/#group-channels)。特定渠道的群聊、附件、回调和原生动作兼容性按交付版本验收。
