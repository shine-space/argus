title: "核心概念"
---

理解应用、数字员工、工作流、资源、任务与业务结果之间的关系。

## 应用与数字员工

应用是企业持续使用的业务产品，组织工作入口、能力、资源、权限和版本。数字员工是应用的对话与执行入口。专业业务工作台和数字员工应操作同一套业务对象，遵循相同的服务端规则。

Agent 定义执行行为、模型和工具等配置；Workflow 定义步骤、数据传递、分支与人工处理。应用引用这些能力，运行时保留具体采用的版本与记录。

## 工作区与协作范围

工作区承载企业资源与权限边界。团队和项目提供具体协作上下文。加入一个项目不自动获得所有关联文件、知识或外部系统数据的访问权。

## 知识与数据

知识用于文档、规则与经验的检索和引用；数据用于结构化记录、字段、口径与受控查询。应用记录用于应用自己的小型业务对象。三者的对象与权限语义不同，不应将所有数据都复制到一个通用记录集合。

## 命令、运行与业务结果

应用命令记录用户的一次执行意图。命令可以关联原 Agent 或 Workflow 运行，包含输入、输出与状态。业务行动是责任人需要完成或验收的业务事项，与 AI 运行分别管理。

文件结果、审批状态、已保存记录和外部系统回执分别证明相应结果。运行成功不自动代表付款、审批、过账或对外发送已经完成。

## 版本与当前权限

应用版本固定行为和能力引用；新任务按其实际运行配置记录上下文。历史任务保留原记录，当前访问仍受权限控制。版本引用或对象 ID 都不是授权凭据。
